## v2.0.0 — eBiz Reconciliation

**Released:** 2026-10-19  
**Phase completed:** 2026-10-08  
**Tag:** [`v2.0.0`](https://github.com/PAC-D/Matalan-Carton-Supply-Report/releases/tag/v2.0.0)

### Highlights

v2 adds the eBiz side of the old `eBiz Report Generator.xlsm`: import vendor exports, match them against the tracker per Sales Order, and produce the Discrepancy Report and Cross Reference.

### What's new

- **eBiz import** — upload one export per vendor. Each upload replaces every existing eBiz row, so upload all vendors together. The preview shows rows, quantity, and total rebate per vendor before you commit.
- **Order matching** — tracker rows are grouped by eBiz Sales Order. An eBiz row matches its `SO_1`, falls back to `SO_2`, or is reported as eBiz-only. Tracker rows without an SO# are reported as a separate group.
- **Discrepancy Report PDF** — five sections:
  1. Tracker orders not found in eBiz
  2. Quantity mismatch, tracker > eBiz
  3. Quantity mismatch, tracker < eBiz
  4. Tracker rows with no SO#
  5. eBiz orders not found in the tracker
- **Cross Reference workbook** — tracker quantity and rebate vs eBiz quantity and rebate per SO#, with quantity difference and status, plus a second sheet for eBiz-only orders.
- **Report integration** — the Discrepancy Report and Cross Reference are included in the normal build, zip, and **Save all** flow when the option is selected.
- **UI** — eBiz upload section on the Import tab and a discrepancy option on the Reports tab.

### Upgrade notes

- Existing `carton.db` files are upgraded automatically to schema version 3. Tracker rows, rates, and saved date corrections are preserved.
- eBiz data starts empty after upgrading. Upload the current vendor exports before building discrepancy reports.
- The eBiz comparison ignores fiscal year and quarter because eBiz rows have no dates. It compares all tracker rows for each selected supplier.
- Every eBiz upload replaces **all** eBiz data, not just the vendors in the new upload. Include every vendor file in the same batch.

### Known limitations

- One eBiz export file per vendor per upload.
- Matching relies on the Sales Order numbers present in the tracker and eBiz exports; there is no manual matching screen.
- The app is single-user, local, and has no login or multi-user concurrency control.
- The tracker workbook must contain cached formula values (open and save it in Excel before importing if it was generated by another tool).

### Verification

- 78 automated checks pass with `python -m pytest check.py -q`.
- Real-data verification covered the Uniglory tracker and eBiz export.

## v1.0.0 — Tracker Reports

**Released:** 2026-10-07  
**Tag:** [`v1.0.0`](https://github.com/PAC-D/Matalan-Carton-Supply-Report/releases/tag/v1.0.0)

### Highlights

v1 replaces the tracker-only part of the old workbook: import `TRACK_STD` and `TRACK_CUS`, keep the data in SQLite, maintain rate tables, and generate the five tracker reports.

### What's new

- **Tracker import** — one or more `.xlsx`/`.xlsm` files, with header detection, template-row skipping, date conversion, and a guard for workbooks without cached formula values.
- **Safe re-imports** — for each sheet, supplier, and shipment month, the imported rows replace the existing group in one transaction. Overlapping files are blocked.
- **Date review** — suspected date errors (day/month swaps, future dates, lost years, implausible PO lead times, text dates) are listed with suggested corrections. Reviewed dates are saved and reused when the same rows return.
- **Supplier merging** — packaging supplier spellings are merged by the first-word supplier key. Reports use the most common spelling as the display name.
- **Rate management** — date-effective PACD and Matalan rebate rates for Standard and Custom cartons. Rates apply by shipment date and can be changed without re-importing data.
- **Reports:**
  - Summary workbook for all suppliers, print-ready A4 portrait.
  - Full Tracker Sheet for PacD (PDF, A4 landscape).
  - Full Tracker Sheet for Matalan (PDF, A4 landscape, no PACD column).
  - Tracker Raw Data workbook per selected quarter.
  - Shipment Tracking export with `TRACK_STD` and `TRACK_CUS` sheets.
- **Delivery** — download a zip bundle or save all files under `Reports/<Month>/<Supplier>/`.

### Upgrade notes

- This is the first release. It creates a new `carton.db`; data from the old `.xlsm` is not migrated automatically. Import the tracker workbooks after starting the app.
- Seed rates are installed on first run:
  - `STD`: 4% PACD / 5% Matalan from 2025-12-01 and 2026-07-01
  - `CUS`: 7.5% PACD / 10% Matalan from 2025-12-01, 7.5% / 5% from 2026-07-01
- The Q3 2026 Custom rebate of 5% is intentional and differs from older workbooks that used 10%.

### Known limitations

- No eBiz import, Discrepancy Report, or Cross Reference in v1; these were added in v2.
- No per-quarter “Tracker Sheet for PacD/Matalan” PDFs; select a single quarter in the Full Tracker report for equivalent content.
- No login, multi-user access, hosting, or row editing in the UI.
- Reports require shipment dates; undated rows are stored but excluded from quarter-based reports.
